# Домашнее задание №3 — вариант 18

Предметная область: **кафедры → преподаватели**. Числовой показатель: `publications` — количество научных публикаций.

## Стек

- C# и ASP.NET Core MVC (`net8.0`)
- SQLite
- Entity Framework Core Code First
- LINQ to Entities

## Что реализовано

- Модели `Department` и `Teacher` со связью один-ко-многим.
- `AppDbContext` с двумя `DbSet<T>`.
- Автоматическое создание SQLite-базы через `EnsureCreated()`.
- Начальные данные: 4 кафедры и 12 преподавателей.
- CRUD для кафедр, включая запрет удаления кафедры со связанными преподавателями.
- CRUD для преподавателей, выпадающий список кафедр и валидация неотрицательного числа публикаций.
- Отчёт из трёх разделов: полный список, количество преподавателей по кафедрам, среднее число публикаций по кафедрам по убыванию.
- Навигационное меню.
- LINQ и EF Core без прямых SQL-строк.

## Быстрый запуск отдельно

Можно открыть файл `Homework3.Variant18.sln` в Visual Studio, назначить проект запускаемым и нажать `F5`.

## Как добавить проект в существующее решение AASOIU

1. Распакуйте папку проекта рядом с папками других работ, например в `homework3`.
2. В Visual Studio нажмите правой кнопкой по верхней строке `Решение "AASOIU"`.
3. Выберите `Добавить → Существующий проект...`.
4. Укажите файл `Homework3.Variant18.csproj`.
5. Нажмите правой кнопкой по проекту `Homework3.Variant18` и выберите `Назначить запускаемым проектом`.
6. Нажмите `F5` или `Ctrl + F5`.

При первом запуске в рабочей папке приложения будет автоматически создан файл базы данных `homework3_variant18.db`.

## Запуск через терминал

```bash
dotnet restore
dotnet run --project Homework3.Variant18.csproj
```

После запуска откройте адрес, показанный в терминале. По умолчанию профиль HTTP использует `http://localhost:5180`.
