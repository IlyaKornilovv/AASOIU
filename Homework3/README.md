# Домашнее задание №3 — вариант 18

Предметная область: кафедры → преподаватели. Числовой показатель: `publications` — количество научных публикаций.

 Стек

- C# и ASP.NET Core MVC (`net8.0`)
- SQLite
- Entity Framework Core Code First
- LINQ to Entities

 Что реализовано

- Модели `Department` и `Teacher` со связью один-ко-многим.
- `AppDbContext` с двумя `DbSet<T>`.
- Автоматическое создание SQLite-базы через `EnsureCreated()`.
- Начальные данные: 4 кафедры и 12 преподавателей.
- CRUD для кафедр, включая запрет удаления кафедры со связанными преподавателями.
- CRUD для преподавателей, выпадающий список кафедр и валидация неотрицательного числа публикаций.
- Отчёт из трёх разделов: полный список, количество преподавателей по кафедрам, среднее число публикаций по кафедрам по убыванию.
- Навигационное меню.
- LINQ и EF Core без прямых SQL-строк.
